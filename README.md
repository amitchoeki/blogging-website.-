# Ink & Ideas — Blogging Website

A responsive sample blogging website made with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and sample blog posts
- `style.css` — responsive layout and visual styling
- `script.js` — category filters, article popups and demo subscription interaction

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `blogging-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for the published URL to appear in the Pages section.

The subscription form is a front-end demonstration only; it does not store email addresses or send emails.
